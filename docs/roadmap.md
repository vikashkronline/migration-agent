# Roadmap

The authoritative phase definitions are in
`plannings/final/agent-platform-master-plan.md`. This summary records the intended progression.

1. Phase 0: project foundation and local diagnostics. **Complete.**
2. Phase 1: deterministic repository discovery and inventory. **Complete.**
3. Phase 2: one read-only analysis agent behind a port.
4. Phase 3: typed migration plans and digest-bound approval.
5. Phase 4: one bounded transformation in staging.
6. Phase 5: allowlisted validation and a terminating repair loop.
7. Phase 6: durable local state, tracing controls, and evaluations.
8. Phase 7: a second migration pair and adapter contract tests.
9. Phase 8: specialist agents only if evaluations justify them.
10. Phase 9: read-only full-stack discovery as the first expansion.
11. Phase 10: production-readiness gap analysis.

Each phase is implemented, reviewed, and committed separately. Technology choices that do
not affect the current phase remain deferred.
