## Completed Phases (Phases 0 – 15)

### Foundation & Core Mechanics (Wave 1)
1. **Phase 0: Project Foundation & Local Diagnostics** — **Complete.**
   CPython 3.12, `uv` package management, typed environment settings, and machine-readable `doctor` diagnostic.
2. **Phase 1: Deterministic Repository Discovery & Inventory** — **Complete.**
   Safe read-only filesystem inspection, file classification, Ember Classic & Angular framework evidence rules.
3. **Phase 2: Provider-Neutral Agent Runtime** — **Complete.**
   `AgentRuntimePort`, Google Gemini (`google-genai`), OpenAI Agents SDK, offline `FakeAgentRuntime`, post-generation evidence audit.
4. **Phase 3: Typed Migration Planning & ADR-1/ADR-2 Storage** — **Complete.**
   Rule-based DAG validator with cycle detection, RFC 8785 canonical JSON metadata hashing, `.agent/` Git governance, SQLite `checkpoints.db`, JSONL `audit.jsonl`.
5. **Phase 4: Staging Workspace Confinement & ADR-8 Controlled Apply** — **Complete.**
   Isolated staging sandboxes, presentational Ember component extraction to modern Angular 17+ Standalone, 4-step controlled apply protocol with verified rollback.
6. **Phase 5: Allowlisted Validation & Bounded Repair Loop** — **Complete.**
   Subprocess confinement, command allowlisting (`tsc`, `ng`, `npm`, `pytest`), secret scrubbing, and bounded repair loop (Invariant 26).
7. **Phase 6: Durable Checkpoint Recovery, Tracing & Evaluation** — **Complete.**
   State machine execution, durable run resumption from checkpoints, local JSONL tracing, offline evaluation harness.
8. **Phase 7: Multi-Framework Expansion & Adapter Contract Tests** — **Complete.**
   AngularJS directive extractor, adapter contract test suite, dynamic capability negotiation.
9. **Phase 8: Specialist Subagents & Plan Critic** — **Complete.**
   Specialist roles (Inventory Interpreter, Migration Analyst, Plan Critic, Repair Diagnostician), budget trackers, deterministic critique aggregators.
10. **Phase 9: Multi-Layer Full-Stack Discovery** — **Complete.**
    Read-only discovery of backend endpoints (FastAPI, Flask, Express) and database schemas (SQL DDL), cross-domain dependency graphs.
11. **Phase 10: Production Readiness & Deployment Hardening** — **Complete.**
    Containerized runner (`docker`), loopback-bound Control Center Web GUI (`agent ui`), security audit logging.
12. **Phase 11: Enterprise Distributed RBAC & Cryptographic Signing** — **Complete.**
    Ed25519 / HMAC authority keys, role-based capability enforcement (`admin`, `lead`, `engineer`, `auditor`), cross-repository clone spoofing defenses.
13. **Phase 12: Project Adoption & Curated Knowledge Lifecycle** — **Complete.**
    Git-native repository adoption (`agent adopt`), ADR management, challenge/solution/learning lifecycle, contextual Q&A with citation verification (`agent ask`).
14. **Section 15: Adversarial Chaos & Security Testing Matrix** — **Complete.**
    Comprehensive attack simulation suite (digest tampering, symlink traversal, shell injection, rollback obstruction, dirty working tree drift).
15. **Milestone: Multi-Binary Aliasing & Distribution Packaging** — **Complete.**
    Symmetrical `agent` and `migration-agent` binaries, PyInstaller packaging specifications, release manifest generation with cryptographic signing.
