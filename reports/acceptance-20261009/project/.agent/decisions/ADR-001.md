# ADR-001: Read-only source and separate migration workspace

**Status:** ACCEPTED
**Decided By:** `user-instructions`

## Context

End-user acceptance migration of a legacy Ember application.

## Decision

Keep the selected Ember source read-only. Create proposals, staging, checkpoints and reports only in the separately initialized migration workspace. Never manually author migrated target application code; use the migration-agent workflow.

## Consequences

Source apply is excluded. Confirm target architecture and provision foundation and validation prerequisites before functional migration tasks.
